# PBR materials

Target surfaces: asphalt (new, worn, patched), concrete, brick, plaster, sandstone, granite, paving slabs, cobblestones, glass, painted metal, roofing and road markings.

Prefer seamless PBR sets with base colour, normal, roughness and metallic maps; ambient occlusion and displacement where available. Record resolution, texel density, tile scale and licence for each material.
