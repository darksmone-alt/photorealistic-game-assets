# Photorealistic Game Assets

Curated asset library for a realistic European metropolis, using Frankfurt am Main as a visual reference.

## Visual target
Dense European city fabric: historic centre, perimeter-block housing, post-war residential districts, modern office towers, commercial streets, transport corridors, parks, riverfronts and industrial edges.

## Asset requirements
- Prefer glTF 2.0 / GLB for real-time use.
- Prefer PBR materials: base colour, normal, roughness, metallic and AO where available.
- Record source URL, creator, exact licence, attribution text, download format and date checked for every asset.
- Add only assets whose licence permits the intended game use and redistribution.
- Keep high-resolution source assets separate from optimised runtime variants.

## Categories
- city: buildings, facades, rooftops, street furniture
- roads: roads, junctions, pavements, crossings, markings
- nature: trees, shrubs, parks, grass, riverbanks
- vehicles: cars, vans, buses, bicycles
- people: pedestrians, clothing, rigs and animations
- animals: urban wildlife and domestic animals
- materials: asphalt, concrete, brick, glass, stone, paving
- lighting: midday, overcast, golden hour, blue hour and night
