# City assets

Scope: European metropolitan architecture inspired by Frankfurt.

Prioritise modular, compatible sets: historic centre, Gründerzeit-style perimeter blocks, post-war residential blocks, contemporary apartments, office towers, retail ground floors, roofs and loading/service areas.

Each model must include source and licence details in the root asset catalogue. Prefer GLB/glTF with PBR textures. Keep facade modules dimensionally consistent and provide scale/origin notes.
